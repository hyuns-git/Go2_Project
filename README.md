# Go2_Project

Unitree Go2 EDU로 5층 건물 안을 자율 주행하고 계단을 올라 옥상까지 가는 프로젝트의 작업 기록입니다. 대화 기록과 Orin2 백업(STATE.md 등)을 원본으로, 시간순으로 정리했습니다.

## 구성

- `sessions/`: 세션별 작업 노트. 파일 이름 앞의 번호가 시간순입니다. 무엇을 했고, 어떤 값을 정했고, 어디서 막혀 어떻게 풀었는지, 아직 확인이 안 된 것이 무엇인지를 적었습니다.
- `guide/`: 노트를 기술별로 다시 묶은 개념 정리(작성 예정).

## 읽는 법

- 각 노트 끝의 "확인이 필요한 항목"은 원본 기록만으로 확정되지 않은 내용입니다. 사실처럼 인용하지 마세요.
- 수치는 원본에서 직접 대조해서 옮겼습니다. 한 노트 안에서 앞선 판단이 나중에 정정된 경우에는 정정된 값과 그 이유를 같이 적었습니다.
- 공개를 위해 회사명, 사람 이름, 계정, 접속 주소, 장비 시리얼 번호는 뺐습니다. IP는 Unitree 기본 내부망(192.168.123.x)과 일반 LAN 대역만 남겼습니다.
